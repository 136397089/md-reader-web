## 背景与痛点

项目虽已启用 `toc` 扩展，但**大纲没有固定可见**。长文档（如《机器学习概述》）只能靠滚轮定位章节，缺少 Obsidian / Typora 式的可点击大纲导航。

## 功能描述

为当前打开的文档生成可点击的章节大纲面板，支持跳转与当前章节高亮。

## 实现方案

- 渲染后的 `.markdown-content` 中解析所有 `h1`–`h6` 标题
- 为每个标题注入 `id`（若 toc 扩展未自动生成）
- 构建大纲面板（可放右侧或侧边栏内），层级缩进反映标题层级
- 点击大纲项 → 平滑滚动到对应标题
- 滚动监听：根据当前可视区域高亮对应的大纲项（scroll spy）
- 面板可折叠，无标题的文档自动隐藏

## 涉及文件

- `src/static/app.js` — 大纲生成、滚动监听、跳转逻辑（在 `loadMarkdownFile` 渲染完成后触发）
- `src/static/app.css` — 大纲面板样式、缩进、高亮态
- `src/template/main_template.py` — 大纲容器 DOM
- `src/translations.py` — 「大纲」标题文案

## 验收标准

- [ ] 打开任意含多级标题的文档，大纲自动生成
- [ ] 层级缩进正确（h1 > h2 > h3 ...）
- [ ] 点击大纲项平滑滚动到对应章节
- [ ] 滚动时当前章节对应的大纲项高亮
- [ ] 面板可折叠，无标题文档时隐藏
