## 背景与痛点

阅读器天然有「保存 / 分享 / 归档」需求，但目前无导出能力，用户只能复制粘贴或截图。

## 功能描述

为当前文档提供「打印 / 导出 PDF」入口，输出干净的正文版式。

## 实现方案

- 头部增加「打印 / 导出 PDF」按钮（调用 `window.print()`）
- 新增 `@media print` 样式：
  - 隐藏侧边栏、Tab 栏、头部工具栏、灯箱
  - 仅显示当前激活 Tab 的 `.markdown-content`
  - 优化字号、页边距、分页（`page-break-inside: avoid` 用于代码块/表格/图片）
  - 白底黑字，确保打印可读
- 导出前可弹出选项（是否包含大纲、是否含图片）— 可选增强

## 涉及文件

- `src/static/app.css` — `@media print` 规则块
- `src/static/app.js` — 打印按钮处理（切换到当前 Tab、隐藏编辑器）
- `src/template/main_template.py` — 打印按钮 DOM
- `src/translations.py` — 「打印 / 导出 PDF」文案

## 验收标准

- [ ] 点击按钮触发浏览器打印对话框（可另存为 PDF）
- [ ] 打印预览中只剩正文，无侧边栏/工具栏
- [ ] 代码块、表格、图片尽量不在分页处断裂
- [ ] 数学公式与图片可正常打印

## 备注

依赖 MathJax 已渲染完成；编辑模式下应禁用导出或自动切回预览。
