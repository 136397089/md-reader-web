## 背景与痛点

几个高频访问的文档（笔记、清单、常用参考）每次都要逐级钻目录才能打开，重复操作多。

## 功能描述

侧边栏顶部新增「⭐ 收藏」区，可对文件加星收藏，一键直达。

## 实现方案

- `localStorage` 存收藏列表：`bookmarks: [{ path, name, added_at }]`
- 文件列表项右侧加 ⭐ 按钮，点击切换收藏态
- 侧边栏「收藏区」始终置顶展示，点击直接 `openFile()`
- 收藏区为空时隐藏或显示引导文案
- 编辑/预览头部也可加快捷「收藏当前文件」按钮

## 涉及文件

- `src/static/app.js` — 收藏存取、切换、渲染
- `src/static/app.css` — 收藏区与星标样式
- `src/template/main_template.py` — 收藏区容器 DOM
- `src/translations.py` — 「收藏」「添加收藏」「取消收藏」文案

## 验收标准

- [ ] 可对任意 Markdown 文件加 / 取消收藏
- [ ] 收藏区置顶，点击直达文件
- [ ] 收藏状态持久化（刷新不丢失）
- [ ] 收藏区为空时有合理占位

## 资源需求与体验影响分析

### 服务端
- **零负担**：纯 `localStorage`，无网络请求。

### 客户端（存储 / 渲染 / 体验）
- **存储**：收藏通常几十条，体积可忽略；但与 003/005/010 共用 localStorage 配额，建议统一命名空间（如 `mr:bookmarks`）便于清理。
- **渲染**：收藏区 DOM 轻量。
- **体验影响**：**正向**。减少高频文档的钻目录操作。注意：收藏的文件若被外部删除/移动，点击会 404，需在 `openFile` 失败时给出"文件已不存在，是否移除收藏"的友好处理，否则产生死链困惑。

## 备注

与 issue 005（最近打开）共享「侧边栏快捷区」的布局，建议统一设计。**localStorage 统一命名空间；处理收藏文件的失效（被删/移动）情况。**
