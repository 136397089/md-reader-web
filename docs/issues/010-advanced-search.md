# 010 - 高级搜索（正则 / 大小写 / 搜索历史）

| 字段 | 值 |
|---|---|
| 编号 | 010 |
| 状态 | 🔴 未开始 |
| 优先级 | 🥉 P2（锦上添花） |
| 类型 | 增强 |
| 涉及端 | 后端 + 前端 |
| 依赖 | 001（全文搜索） |

## 背景与痛点

基础全文搜索（issue 001）上线后，进阶用户需要：正则匹配、大小写敏感、按目录范围搜索、以及保留搜索历史避免重复输入。

## 功能描述

在 001 基础上扩展搜索能力与历史记录。

## 实现方案

- 后端 `/api/search` 增加参数：
  - `regex=true` — 启用正则（注意 DoS 防护，限制复杂度 / 超时）
  - `case_sensitive=true`
  - `path=<scope>` — 限定搜索目录范围
- 前端搜索框增加切换项（正则 / 大小写 / 范围）
- 搜索历史：`localStorage` 存最近搜索词，下拉展示，可清除

## 涉及文件

- `src/routes.py` — 扩展 `/api/search` 参数与匹配逻辑
- `src/static/app.js` — 高级选项 UI、搜索历史
- `src/static/app.css` — 选项与历史样式
- `src/translations.py` — 相关文案

## 验收标准

- [ ] 支持正则表达式搜索
- [ ] 支持大小写敏感切换
- [ ] 支持限定目录范围
- [ ] 搜索历史可查看与清除
- [ ] 正则有超时 / 复杂度保护，不致服务卡死

## 备注

必须在 001 完成后开展；正则需做 ReDoS 防护。
